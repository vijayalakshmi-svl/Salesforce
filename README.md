# Salesforce Placement Management System

A Salesforce-based project that automates key processes in a college placement management system using declarative tools. The project implements Validation Rules and Record-Triggered Flows to ensure data accuracy, streamline application management, and reduce manual effort.

## 🚀 Key Features

- Automatically populates the Application Date using Before-Save Record-Triggered Flows.
- Sends confirmation email notifications to the Placement Officer after an application is submitted.
- Automatically creates an Offer Letter when a student's application status is marked as **Selected**.
- Implements Validation Rules to enforce business requirements and maintain data integrity.
- Streamlines the placement workflow by following Salesforce's **"Clicks Before Code"** approach.

## 💡 Project Highlights

- Built entirely using Salesforce declarative automation tools.
- Improved data accuracy and reduced manual intervention.
- Designed scalable and maintainable business processes.
- Demonstrates real-world Salesforce automation practices.

> This project showcases how Salesforce can be used to build an efficient and automated Placement Management System without writing custom code.
