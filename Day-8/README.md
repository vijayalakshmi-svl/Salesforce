# 📌 Sprint Overview

Day 8 focuses on **Asynchronous Apex**, which allows long-running processes to execute in the background without affecting the user experience.

This sprint introduces the four major asynchronous processing techniques available in Salesforce.

- 🚀 Future Methods
- 🚀 Queueable Apex
- 🚀 Batch Apex
- 🚀 Scheduled Apex

These concepts are widely used in enterprise Salesforce applications for processing large volumes of data efficiently.

# 💡 Key Concepts Learned

## 🔹 Future Method

- Runs asynchronously
- Executes in the background
- Suitable for lightweight operations

---

## 🔹 Queueable Apex

- Supports complex objects
- Better than Future Methods
- Allows Job Chaining

---

## 🔹 Batch Apex

- Processes millions of records
- Executes in smaller batches
- Efficient for large datasets

---

## 🔹 Scheduled Apex

- Executes automatically
- Uses CRON expressions
- Ideal for recurring jobs
